# Laços de Repetição – C#

## Descrição

Conjunto de atividades desenvolvidas para praticar estruturas de repetição e iteração
utilizando a linguagem C# em aplicações de console.

## Objetivo

Aplicar conceitos fundamentais de programação com laços, como:

- Laços for (iteração com contador)
- Laços while (iteração condicional)
- Laços do-while (iteração com verificação ao final)
- Operadores de comparação e lógicos
- Acumuladores e contadores

## Atividades

Cada pasta contém uma atividade independente:

1. Soma_1_a_N
2. Tabuada
3. Numeros_Pares
4. Calculo_Fatorial
5. Calculo_Media
6. Contagem_Regressiva
7. Soma_N_Numeros
8. Multiplo_3
9. Calculo_Fatorial_While
10. Numeros_Impares
11. Tabuada_While
12. Maior_Numero
13. Par_ou_Impar
14. Calculo_Media_While
15. Calculadora_do-while

## Tecnologias utilizadas

- C#
