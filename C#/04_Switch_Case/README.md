# Switch Case e Tratamento de Erros – C#

## Descrição

Conjunto de atividades desenvolvidas para praticar estruturas condicionais avançadas
(switch case) e tratamento de exceções utilizando a linguagem C# em aplicações de console.

## Objetivo

Aplicar conceitos fundamentais de programação com seleção múltipla e tratamento de erros, como:

- Switch Case (seleção de múltiplas opções)
- Statements break e default
- Try-catch (tratamento de exceções)
- Validação de entrada
- Conversão de tipos
- Operadores condicionais

## Atividades

Cada pasta contém uma atividade independente:

1. tipo_de_veiculo
2. selecao_personagem
3. menu_operacao_matematica
4. sistema_restaurante
5. calculo_preco_desconto
6. conversor_moeda
7. calculo_imc
8. calculo_imc_validacao
9. calculadora_tratamento_erro
10. exemplo_tratamento_erro
11. divisao_tratamento_erro

## Tecnologias utilizadas

- C#
