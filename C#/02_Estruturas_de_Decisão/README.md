# Estruturas de Decisão – C#

## Descrição

Conjunto de atividades desenvolvidas para praticar operações de estrutura lógica com operados If/Else
utilizando a linguagem C# em aplicações de console.

## Objetivo

Aplicar conceitos fundamentais de programação, como:

- Estruturas de decisão (if/else)
- Lógica de decisão
- Operadores de comparação
- Operadores lógicos

## Atividades

Cada pasta contém uma atividade independente:

1. Decisão entre Maior e Menor
2. Cálculo de Salário e Horas Extras
3. Cálculo de IMC
4. Classificação do Triângulo
5. Cálculo de Imposto de Renda
6. Calculadora
7. Calculo de Plano Cartesiano

## Tecnologias utilizadas

- C#
