# Exercícios Práticos em C#

## Descrição

Conjunto de atividades desenvolvidas para praticar conceitos fundamentais de programação em C#, incluindo estruturas de controle, loops e operações matemáticas em aplicações de console.

## Objetivo

Aplicar conceitos básicos de programação, como:

- Estruturas condicionais (if-else)
- Loops (for, while)
- Operações aritméticas
- Entrada e saída de dados
- Validação de entrada

## Atividades

Cada pasta contém uma atividade independente:

1. 01_contagem_pares
2. 02_calculadora_somatoria
3. 03_contagem_impares
4. 04_calculadora_pares_impares
5. 05_calculadora_media
6. 06_multiplos
7. 07_somador_numeros
8. 08_jogo_sorteio
9. 09_calculadora_menu

## Tecnologias utilizadas

- C#
